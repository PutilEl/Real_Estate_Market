# 🏠 **Проект «Анализ рынка недвижимости»**

Компания из Петрозаводска, работающая в сфере недвижимости, планирует 
перенести свой главный офис в Санкт‑Петербург и начать активную работу 
в регионе, включая Ленинградскую область. Чтобы грамотно выстроить этот 
переход, агентство обратилось за анализом в аналитическое агенство.

🎯 **Цель проекта** - провести анализ объявлений о продаже жилой недвижимости в 
Санкт-Петербурге и Ленинградской области для определения наиболее перспективных 
сегментов недвижимости.

📋 **Задачи проекта:**
1. Провести исследовательский анализ данных;
2. Решить ad-hoc задачи;
3. Сформулировать выводы и рекомендации для бизнеса;
4. Доработать дашборд.

📚 **Источники информации**

В данном проекте использована база данных (БД) архива сервиса Яндекс Недвижимость: 
в ней находятся объявления о продаже квартир в Санкт-Петербурге и 
Ленинградской области за несколько лет. 

🛠️ **Инструменты и технологии**
- Stack: PostgreSQL;
- Клиент для работы с БД: DBeaver;
- Yandex Datalens — визуализация данных и построение дашборда;
- SQL — подготовка данных и агрегаций;
- Использованы JOIN, агрегатные функции, подзапросы, CTE.

## 📊 **1. Исследовательский анализ данных**

На данном этапе проводится оценка объёма данных, разброс метрик и поиск ошибок 
вроде аномальных или неправдоподобных значений.

## ⚡ **2. Решение ad-hoc задач**

На данном этапе представлены следующие ad-hoc задачи:
- Выявление перспективных направлений на рынке недвижимости и анализ влияния 
характеристик квартиры на скорость её продажи;
- Анализ сезонности рынка;
- Исследование региональных особенностей для Ленинградской области;
- Аналитические заметки по каждому блоку исследования.

## 💡 **3. Выводы и рекомендации для бизнеса**

На данном этапе проекта сформулированы выводы и рекомендации для 
бизнеса по полученным результатам выполненных ad-hoc задач.

## 📈 **4. Доработка дашборда**

Доработан существующий дашборд по требованиям заказчика. 
Добавлены новые фильтры и возможности для анализа данных, 
а также улучшено отображение информации об объектах недвижимости.

Ссылка на дашборд: https://datalens.yandex/jnv959yljwiq3

### 🏆 **Результаты**
В репозитории расположен код SQL-запросов, их результаты и 
рекомендации для бизнеса, а также, доработанный дашборд.

### 📁 **Используемые данные**
Проект разработан на основе базы данных, предоставленной **Яндекс Практикум** 
во время обучения. Все данные предоставлены исключительно в образовательных целях.
